## 1. Overarching Job Goal & Acceptance Criteria
> **PRIMARY GOAL:** Eliminate the import freeze by removing every browser-native file picker (`<input type="file">` / OS document picker, which backgrounds the browser and gets the Termux/Pydroid process killed) and replacing it with a Flask/Python server-side file browser that runs entirely inside the app page. Separate non-image media from images in the Media Library.

### Key Acceptance Criteria
- [x] No `<input type="file">`, `FileReader`, or `showOpenFilePicker` remains in any user-facing import UI (Admin, Page Editor V1, Page Editor V2)
- [x] One reusable picker (`CMSFilePicker`) + `/fb/api/*` browse API, usable for images, media, HTML, ZIP apps, code, markdown, key files, any file
- [x] All import paths accept server-side picked paths and validate them (roots, symlink escape, secrets dir deny, extension allowlist, size cap)
- [x] Media Library split into Images / Video / Audio / Documents / YouTube / Links sections
- [x] Existing behaviour preserved (SVG sanitising, dedupe hash, serial thumbnail worker, uuid-keyed records, legacy POST upload routes still work)
- [x] No edits under `src/lib/` (Library Immutability)
